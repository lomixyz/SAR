Saudi Riyal New Symbol

Replace the "SR" text with the new official Saudi Riyal sign on every amount in Odoo — without changing any of your fonts.

Key features

Official Unicode sign

Uses the official code point U+20C1 (Saudi Riyal Sign), so the symbol stays correct in exports, APIs and on devices that already support it.

Your fonts stay untouched

A tiny web font (under 1 KB) is used only for the riyal sign. Every other character keeps Odoo's fonts, your website theme fonts and your report layout font.

Everywhere amounts appear

Backend (lists, forms, totals), website, customer portal and Point of Sale.

PDF reports

Invoices, quotations, orders and every PDF report, with any company layout font: Lato, Roboto, Open Sans, Montserrat, Oswald, Raleway or Tajawal.

Zero configuration

Install the module: the SAR currency gets the new sign, placed before the amount. Nothing else to set up.

Clean uninstall

Uninstalling restores Odoo's default "SR" symbol, so no unreadable characters are left behind.

Installation

  1. Install the module from Apps.
  2. Make sure the SAR currency is active (it is by default with the Saudi localization).
  3. Refresh your browser — amounts in SAR now show the new sign.
